담당자: 김수연

## 1. 담당 범위

본 절은 예측 모델의 독립 검증, 추천·재배치 결과 검증, 이용자 UI,
대표 사용자 시나리오와 서비스 품질 평가를 통합한다. 구현 여부와
정량 성능을 구분하고, 아직 선행 데이터 또는 리뷰가 필요한 결과는
확정 수치와 섞지 않는다.

## 2. 모델 성능 검증

최종 Random Forest는 2025-08-01부터 2026-07-31까지의 데이터에 대해
시간순 70/15/15 분할과 두 개의 60분 purge gap을 적용했다. 최종 test
구간은 2026-06-07 06:00부터 2026-07-31 23:45까지이며, 950,455개 행을
대상으로 독립 재현했다.

| Segment | 15분 B1 대비 | 30분 B1 대비 | 60분 B1 대비 |
|---|---:|---:|---:|
| ALL | -2.42% | +2.22% | +7.33% |
| ACTIVE | +0.88% | +5.41% | +10.52% |
| PEAK | +7.19% | +12.61% | +17.83% |
| ACTIVE ∩ PEAK | +10.71% | +16.63% | +21.92% |

전체 15분 예측은 persistence baseline B1보다 2.42% 낮으므로 최종
모델을 모든 조건에서 우수하다고 해석하지 않는다. 반면 혼잡 시간과
활동 대여소에서는 예측 시간이 길어질수록 개선폭이 커졌고,
ACTIVE ∩ PEAK 60분에서 21.92% 개선됐다.

모델 artifact와 feature table의 SHA-256, 입력 변수 46개, test 행 수,
활동 대여소 47개 및 12개 segment/horizon 지표를 독립적으로 확인했다.
저장 지표와 재계산 지표의 최대 절대 차이는 `4.69e-12`로 허용오차
`1e-10` 이내였다.

## 3. 오류 특성

전체 residual 평균은 0에 가까워 전역적인 과대·과소예측 편향은 작았다.
그러나 오차는 17~18시, 08시, 활동량이 많은 대여소와 60분 horizon에
집중됐다. Random Forest 60분 MAE는 전체 1.579대에서 17시 2.745대로
증가했다. 가장 큰 오류는 드문 수요 충격을 평균적 패턴으로 축소한
경우였으므로 운영환경에서는 최근 극단 활동 감지와 불확실성 안내가
필요하다.

## 4. 이용자 추천

추천은 거리와 사용자가 도착할 시점의 가용성을 각각 50%로 결합한다.
출발 추천은 `bikes_expected`, 도착 추천은 `docks_expected`를 사용하고,
0·15·30·60분 예측 anchor 사이를 도보시간에 맞춰 선형보간한다.

```text
distance_score = 1 - min(distance_m / 800, 1)
availability_score = min(expected_available / 3, 1)
score = 0.5 × distance_score + 0.5 × availability_score
```

점수, 예상 가용 수량, 거리, 대여소 ID 순으로 결정적으로 정렬하고
출발·도착 각각 상위 3개를 반환한다. 추천 카드는 대여소명, 거리,
도보시간, 현재 재고, 미래 예상 가용성, 점수 구성과 추천 이유를 제공한다.

## 5. 추천 정량평가 상태

Top-3 공식 평가는 각 요청의 `t+h` 실제 재고 snapshot을 사용해야 한다.
출발은 실제 자전거 수, 도착은 실제 빈 거치대 수를 기준으로 최소 가용
(1개 이상)과 안정 가용(2개 이상)을 15·30·60분별로 평가한다.

평가기와 결과표·그래프 생성기는 구현했으나, 현재 저장소와 김수연에게
공유된 artifact에는 hold-out snapshot 및 좌표·capacity가 있는 station
master가 없다. 역사적 대여·반납량 `delta_hist`를 실제 재고로 대체하면
사전 평가계약을 위반하므로 공식 hit rate는 입력 수령 후 확정한다.

| 항목 | 현재 상태 |
|---|---|
| Top-3 평가 코드 | 완료 |
| 1+/2+ 기준 | 완료 |
| horizon·micro 집계 | 완료 |
| 입력 checksum·request audit | 완료 |
| 공식 hold-out hit rate | snapshot 입력 대기 |

## 6. 재배치 효과 평가

재배치 backtest PR #75는 181개 snapshot 대여소, 6,026개 기준시각,
15·30·60분 총 18,078개 case를 평가했다. VEHICLE_CAP=20의 oracle
counterfactual 결과는 shortage 약 23.9%, 위험 대여소 약 15.2~15.4%
감소였다. CAP 10/20/40에서 shortage 감소율은 약 12.0%/23.9%/47.4%로
재배치 효과가 horizon보다 차량 적재량에 더 민감했다.

이 결과는 미래 실제 재고를 미리 아는 oracle upper bound이므로 실제
모델 예측을 사용한 실현 효과로 해석하지 않는다. 또한 본 보고서 작성
시점에 PR #75는 리뷰 대기이므로 병합 후 수치와 방법을 다시 확인해
최종본으로 확정한다.

## 7. 이용자 UI 및 E2E QA

구현·검증한 이용자 흐름은 다음과 같다.

1. 출발지와 목적지 독립 검색
2. 주변 대여소 및 지도 marker 표시
3. 출발·도착 Top-3 추천 카드 표시
4. 미래 자전거·빈 거치대와 추천 이유 표시
5. 이용자·운영자 탭 전환
6. 검색 오류와 모바일 레이아웃 처리

대표 경로는 세종대학교→성수역, 건대입구역→서울숲,
어린이대공원→왕십리역이다. 각 경로에서 출발·도착 카드 3개씩,
추천 이유와 지도 marker 8개를 확인했다. 두 글자 미만 검색 안내,
운영자 우선순위 표, 390×844 viewport의 가로 overflow도 검사했으며
브라우저 E2E 7개가 모두 통과했다.

테스트 과정에서 `main.tsx`가 탭 컨테이너 대신 이름이 유사한 이용자
화면 파일을 가져오는 통합 오류를 발견했다. 진입점을 명시한 뒤 전체
회귀 테스트를 다시 수행해 이용자·운영자 기능이 함께 유지됨을 확인했다.

## 9. 결론

모델과 UI의 재현성·기능 동작은 확인됐고, 고수요·혼잡 구간에서 최종
모델의 운영 가치가 가장 크게 나타났다. 남은 핵심은 실제 hold-out
재고 snapshot으로 추천 성공률을 확정하고, oracle 재배치 효과와 실제
예측 기반 효과를 구분해 보고하는 것이다. 이 두 결과가 확정되면 최종
정량표와 발표 자료를 갱신한다.
