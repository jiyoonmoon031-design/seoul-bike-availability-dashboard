## 범위

실시간 대여소 재고, 현재시간 예측, Best 3 경로 추천, 자연어 추천 설명과 이용자 화면으로 이어지는 흐름 및 장애 대체 정책을 검토하였다.

## 구현·검증 완료 범위

- 실시간 대여소 상태를 예측 후보에 연결
- 예측 결과를 출발·도착 추천과 경로쌍 순위에 연결
- 현재시간 특징행이 없을 때 B3 요일·시간대 평균 적용
- B3를 사용할 수 없을 때 B1 지속성 변화량 0 적용
- 실시간 재고 누락, 잘못된 재고, capacity 초과 상태를 서로 다른 경고로 구분
- 자연어 추천 설명 실패 시 기존 구조화 추천 결과 유지
- 수치·점수·순위 계산과 LLM 설명 기능 분리
- 이용자 Best 3 카드와 지도 표식 표시
- 운영자 부족·공급 대여소 및 재배치 매칭 표시
