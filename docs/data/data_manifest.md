# Data Manifest

## 1. Rental / Return History

- Dataset: 서울시 공공자전거 대여소별 대여/반납 승객수
- Period: 2025-08-01 ~ 2026-07-31
- Source: 서울 열린데이터광장
- Storage: Google Drive/ddareungi_data/raw/trip/
- Scope: 서울시 원본 데이터
- Format: CSV
- Rows: 추후 확인
- Columns:
  - 집계\_기준
  - 기준\_날짜
  - 기준\_시간대
  - 시작\_대여소\_ID
  - 종료\_대여소\_ID
  - 전체\_건수

## 2. Weather Observation

- Dataset: 기상청 AWS 시간자료
- Period: 2025-08-01 00:00 ~ 2026-08-01 00:00
- Source: 기상청 기상자료개방포털
- Station: 성동 AWS (421)
- Storage: Google Drive/ddareungi_data/raw/weather/
- Scope: 광진구·성동구 대표 기상 관측소
- Format: CSV
- Rows: 8,761
- Columns:
  - 지점
  - 지점명
  - 일시
  - 기온(°C)
  - 풍향(deg)
  - 풍속(m/s)
  - 강수량(mm)
  - 습도(%)
- Generated by: 기상청 기상자료개방포털에서 다운로드
- Validation: scripts/validate_weather.py

- Rows: 365

## 4. Target Stations

- Dataset: 광진구·성동구 대상 따릉이 대여소
- Source:
  - 서울시 공공자전거 대여소 정보 API (tbCycleStationInfo)
  - 서울시 공공자전거 실시간 대여정보 API (bikeList)
- Storage: Google Drive/ddareungi_data/reference/target_stations.csv
- Format: CSV
- Rows: 221
- Columns:
  - station_id
  - station_name
  - district
  - address
  - latitude
  - longitude
  - capacity
- Scope: `tbCycleStationInfo` 기준 광진구·성동구 대상 대여소 전체
- Total target stations: 221
- Observed in historical trip data: 185
- Observed in realtime `bikeList`: 177
- Note: 데이터에서 관측되지 않았다는 사실만으로 폐쇄·비운영 대여소로 판단하지 않는다.
