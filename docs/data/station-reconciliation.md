# Station Mapping / Reconciliation Report

## 1. 기준 대여소

광진구·성동구 대여소 마스터를 기준으로 총 221개 대여소를 관리한다.

## 2. 과거 대여·반납 데이터

2025-08 ~ 2026-07 기간의 과거 대여·반납 데이터를 확인한 결과,
대여 또는 반납 데이터에서 한 번 이상 관측된 대여소는 185개이다.

- 기준 대여소: 221개
- 과거 데이터 관측 대여소: 185개
- 과거 데이터 미관측 대여소: 36개

## 3. 실시간 대여소 현황

실시간 따릉이 API에서 관측된 대상 대여소는 177개이다.

- 기준 대여소: 221개
- 실시간 API 관측 대여소: 177개
- 실시간 API 미관측 대여소: 44개

## 4. 비교 결과

과거 데이터에서 미관측된 36개 대여소는 모두
실시간 API 미관측 44개 대여소에 포함된다.

나머지 8개 대여소는 과거 데이터에서는 관측되었으나
실시간 API에서는 관측되지 않았다.

데이터에서 관측되지 않았다는 사실만으로 해당 대여소를
폐쇄·비운영 대여소로 판단하지 않는다.

대여소 연결은 `station_id`를 기준으로 수행하며,
임의로 다른 대여소 ID에 매핑하지 않는다.
