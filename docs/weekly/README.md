# Weekly Technical Deliverables

주차별 팀 기술 진행사항과 산출물 위치를 기록합니다.

학교에 각 팀원이 개별 제출하는 주간학습보고서와는 별도입니다.

## 파일명

```text
w01-summary.md
w02-summary.md
...
w12-summary.md
```

## 교차 검토 예외

Reviewer가 해당 주차의 특정 항목을 직접 작성했다면 그 항목은 본인이 승인하지 않습니다.

다음 사람이 대리 검토합니다.

| Week | 원 Reviewer | 본인 작성 항목 | 대리 Reviewer |
|---|---|---|---|
| 03 | 문지윤 | feature / baseline | 김수연 |
| 06 | 조성은 | backend integration | 김수연 |
| 09 | 문지윤 | LLM payload / prompt | 김수연 |
| 11 | 문지윤 | model fallback | 조성은 |
